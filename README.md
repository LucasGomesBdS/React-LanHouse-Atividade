# Lan House Web

Atividade avaliativa de React (Componentes, Props e Rotas).

## Como executar
```
npm install
npm run dev
```

## Onde está cada conceito
- **Componentes:** `src/components` (Header, Menu, Footer, Card, Button)
- **Props:** `Card` recebe titulo, imagem, descricao, preco e categoria. Os dados ficam em `src/pages/Produtos.jsx` e são renderizados com `.map()`
- **Rotas:** `src/App.jsx` (/, /produtos, /sobre, /contato, *) e links em `src/components/Menu.jsx`
